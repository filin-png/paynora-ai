# Marketing Showreel Package — Developer Portfolio Video

Source material for a premium 30–40s vertical (9:16) advertising video promoting the developer, using PAYNORA AI and NEXORA AI as portfolio evidence.

This directory is intentionally kept separate from the application source tree — nothing here affects either product's production code.

## Contents

1. `01-project-analysis/` — deep code-verified analysis of both repos, positioning
2. `02-selected-screens/` — which screens were chosen and why
3. `03-screenshots/` — 9 real Paynora screenshots + explanation of why Nexora couldn't be captured
4. `04-storyboard/` — visual concept + full second-by-second storyboard (40s cut)
5. `05-video-prompts/` — per-scene AI video generation prompts (prompt/negative/generator/duration)
6. `06-copy/` — Russian ad copy (main + 20s + final CTA)
7. `07-music-sound/` — music/sound design brief
8. `08-editing-guide/` — assembly, grading, export specs
9. `09-20sec-version/` — condensed cut storyboard
10. `10-final-production-checklist/` — what's done vs. what needs manual action

Start with `10-final-production-checklist/` for the fastest overview, or `01-project-analysis/` for the full technical basis behind every claim in the copy.
